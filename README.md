# Lumenforge

Lumenforge is a bench for new WLED looks. The strip at the top is a live preview of effects that are not in stock firmware.

Stock WLED cannot store a new algorithm over Wi-Fi. This app previews original looks, streams pixels while the page is open, saves cousin presets of built-in effects, and exports a WLED 0.15 usermod plus MoonModules ARTI-FX scripts.

## Run

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
